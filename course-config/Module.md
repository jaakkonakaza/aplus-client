# Module course-config

Course manifests shared by A+ Courses and template consumers.
Kotlin callers use [CourseConfig.Document](https://jaakkonakaza.github.io/aplus-client/course-config/fi.aalto.cs.aplus.courseconfig/-course-config/-document/index.html). Scala callers can use the course-config-scala factories.

# Package fi.aalto.cs.aplus.courseconfig

Read manifests with [CourseConfig.parse](https://jaakkonakaza.github.io/aplus-client/course-config/fi.aalto.cs.aplus.courseconfig/-course-config/parse.html) and check them with [CourseConfig.validate](https://jaakkonakaza.github.io/aplus-client/course-config/fi.aalto.cs.aplus.courseconfig/-course-config/validate.html).
[CourseConfig.Document.toJson](https://jaakkonakaza.github.io/aplus-client/course-config/fi.aalto.cs.aplus.courseconfig/-course-config/-document/to-json.html) validates before writing.
See [CourseConfig.Document](https://jaakkonakaza.github.io/aplus-client/course-config/fi.aalto.cs.aplus.courseconfig/-course-config/-document/index.html) for JSON examples and field descriptions.
